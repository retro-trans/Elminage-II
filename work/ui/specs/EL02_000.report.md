# EL02_000 UI texture report (Elminage II)

Sheet: `ANIME/EL02_000.GIM` (512x512 index-8). Spec: `work/ui/specs/EL02_000.json`, preview: `work/ui/preview/EL02_000.png`, built GIM: `work/build/img/EL02_000.GIM`.

72 word labels + 16 stacked monster-type codes (104 label entries, 81 erase rects). All labels fit; 0 build errors. Erase-only render (spec with `labels` emptied) checked: no Japanese pixels remain; the only text-coloured pixels left are the kept non-Japanese glyphs (～, %, ＡＣＨＰ, △, □, slashes, plate ornaments).

## Method

- Reference: Elminage III `work/ui/specs/EL02_000.json` / `.report.md`. The Elm II sheet has the same layout: every glyph strip (y80-180), the 売却/購入 pair, the face button and the monster-type block are pixel-identical to Elm III (tolerant diff = 0 over every reused erase rect); plates sit at the same places in a different (greyer) colour scheme, and their Elm III copy columns (398, 391, 192, 412, 355) are text-free here too. Elm III rects, colours and translations were reused unchanged for those.
- 12px pink pieces: erased to transparent (`fill:7,5,3,0`) over the ink box, English drawn left-aligned with the 12px font (spacing 1, else 0) in the sampled text colour, inside the original ink extent.
- Plates: `copy:` of a clean column of the same plate, English centred in white with the 12px font.
- Face-icon button: interior rebuilt with fills sampled from the original (as Elm III), 4 staggered lines.
- Monster-type block (x176-382, y233-255): the kanji are on a **13 px pitch** (16 columns, x=176+13*i, last ink column 381). Elm III's spec used a 12 px pitch and a flat fill ending at x368, which on this sheet left the 神影 column untouched; here the block is cleaned with `copy:386` (the panel is a vertical gradient, so a clean column keeps it) and each 2-letter code is stacked one letter per kanji in a 12x12 cell on the 13 px grid.
- Differences from Elm III: 鉱石2/鉱石1 are at x441, y48/y60 (Elm III x438, y31/43); erase rects and labels moved. Not on this sheet (dropped): 所持金, スキル残回数, 消費, 現在, 呪文リスト.

## Risks / in-game checks

- Not verified in game (no emulator run); UV rects of the composed strip pieces are unknown. Pieces drawn 1-2 px outside the Japanese ink (Sum, Res) could lose an edge column if the game's rect is ink-tight (same as Elm III).
- メインサブ treated as one piece ("M/S"); if drawn as separate メイン / サブ sprites the halves would appear apart.
- 神影 code "Di" follows Elm III; the Elm II glossary name is "Godshade" — if a Godshade-based code is wanted (e.g. "Gs"), change the last column's two labels. Codes must match whatever EL01_000 and the eboot use once those are done.
- 冒険者 plate "Adv." (glossary "adventurer" does not fit the ~46 px plate).
- Abbreviations forced by width (as Elm III): No Lim, M/S, Rng, Crs, Act, Sp.Res, ?Name, AC-, Abl, Rce, Aln, Atks, WpnGrd, Barr., Rslt, #1/#2, Brth, Drw, Pri, Alch., Sum, FS, Cure%, Res, Avg., Btn, Sort Up/Dn, Adv.
