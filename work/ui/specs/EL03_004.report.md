# EL03_004 - Elminage town buttons and compass buttons

Spec: `work/ui/specs/EL03_004.json`. Output: `work/build/img/EL03_004.GIM`. Preview: `work/ui/preview/EL03_004.png`.

There are 15 Japanese labels, each in 3 states, so 45 sprites. All 45 are translated. This sheet holds the Elminage-town facility buttons and the compass menu and target list. It has no gallery or music buttons.

## Layout
- Rows 0-3 (y0-78): 112x18 plates in 114 px columns (selected x0, normal x114, disabled x228). These are the Elminage town buttons, the same plate art as EL03_003.
- Rows 4-14 (y80-298): the same plate art shortened to 94x18 (20 px cut from the middle; the left swirl, bottom ornament at rel x50-55 and right tail match the 114 px plate). They sit in 96 px columns: x0 / x96 / x192. These are the compass menu (Fame, Search) and the compass target list (Jewel Ring and the 8 divine relics).
- Colours are the same as EL03_003. Selected: 255,255,255 / outline 126,31,21. Normal: 252,222,185 / 30,20,12. Disabled: 102,102,102 / 30,17,10.

## Method
1. 114 px reference plate: Small Talk (row 3, y60). In each state, rel x14-47 is blitted from rel x58-91 of the same plate. Rows 0-2 get rel x12-111 (20 rows) from the reference of their state.
2. 94 px reference plate: Fame (row 4, y80). Its rel x14-71 is blitted from the cleaned 114 px reference of the same state, which carries the same plate texture. The 94 px plate's own right tail (rel x72-93) is kept. Rows 5-14 get rel x12-93 (20 rows) from it.
3. Text uses the 16 px font, left-aligned. The ink starts at rel x15. Spacing 1 is used where it fits. Breastplate uses spacing 0 in 3 segments, with 1 px gaps around the l.
4. Erase-only check: `scratch_EL03_003_EL03_004_eraseonly.json`. Every plate matches the reference of its state and group (no visible pixel differs by more than 60), and the references were checked at 4x. No Japanese is left.

Relic names: the glossary and eboot (eb@0895042c-08950498) full names run 98-152 px at spacing 0, and these plates hold 78. Each of the 8 divine relics is a different kind of item, so the item noun alone is unambiguous in this list. After the player picks one, the eboot message "You set the compass to %s." prints the full name. The other option, inverted forms like "Wrath Sword", would make up names the script never uses.

## Risks / in-game checks
- Relic shortening: confirm that "Sword", "Shield" and the rest are acceptable on the compass target list. Otherwise the virtue names, or 12 px text, would be needed.
- Breastplate (spacing 0) ends at rel x91 on a 94 px plate, which is tight against the right curve. The Japanese reached rel x92-95.
- Col. Corridor and Rec. History are abbreviations. The help line shows the full names.
- Only the palette indices change. Size, format and palette are unchanged.
