# EL03_003 - town talk / place / option-tab / temple buttons

Spec: `work/ui/specs/EL03_003.json`. Output: `work/build/img/EL03_003.GIM`. Preview: `work/ui/preview/EL03_003.png`.

There are 23 Japanese labels, each in 3 states, so 69 sprites. All 69 are translated. The sheet has no other Japanese.

## Layout
- The plates are 112x18, in 114 px columns: selected x0, normal x114, disabled x228. Rows are at y = 20*r (r 0-22, last plate y440-457). Rows 18-19 of each cell hold a faint shadow at alpha 5-64.
- Selected is a silver gradient plate with white text and a dark red outline. Normal is a dark red plate with cream text. Disabled is a dark plate with grey text. The colour scheme differs from Elminage III, but the plate shape and grid are the same.
- Outside the text, the plate art is identical in every row for the normal and disabled states (checked pixel by pixel). For selected, it is identical apart from the shadow rows and the noisy bottom edge.

## Method
1. Reference plate: Pray (row 21, y420). The Japanese spans rel x16-44. In each state, rel x14-47 is blitted from the same plate's clean texture at rel x58-91. The offset is 44, which is even, so the dither phase is kept. The source avoids the bottom ornament at rel x50-55 and the right swirl from rel x93.
2. Every other plate gets rel x12-111 for all 20 rows (plate plus shadow rows) blitted from the reference of its state. The left swirl (x0-11) is kept. x112-113 is transparent.
3. Text uses the 16 px font, left-aligned. The ink starts at rel x15, and the 1 px outline sits at x14, just right of the left swirl. Colours were sampled from the original glyphs: selected 255,255,255 / outline 126,31,21; normal 252,222,185 / 30,20,12; disabled 102,102,102 / 30,17,10.
4. Spacing 1 is used when the label fits in 96 px (ink up to rel x110). Otherwise the label uses spacing 0, split into segments that keep a 1 px gap around narrow glyphs (i l I ' . j), so pairs do not merge. Two labels (Grand Merchant, Semnadoc Cath.) also start at rel x13 and use a 4 px word space. Harjiradam is drawn as "Har" + "jiradam" with the j pulled 2 px left, because the font's j has a wide left bearing ("Har jiradam" otherwise).
5. Erase-only check: `scratch_EL03_003_EL03_003_eraseonly.json` is the same erase list with no labels. Rendered, every one of the 69 plates matches the reference plate of its state (no visible pixel differs by more than 60), and the references were checked visually at 4x. No Japanese is left.

## Risks / in-game checks
- Many labels run past where the Japanese word ended, and some run over the right swirl (listed above). Each sprite is the whole plate, so the text stays inside the sprite. Check that nothing in-game is drawn over the right end of the buttons (cursor, icons).
- The spacing-0 labels (Bilente's Shop, Grand Merchant, Blast Furnace, Semnadoc Cath.) and the two 4 px word spaces are the tightest. Check them for readability at native size.
- Open naming points for the lead:
  - HELP_TEXT 85:7/85:9 and CHRTMPLT 161:3 say "Old Aim", but the glossary and the reviewed script say "Oldaim". The button follows the glossary.
  - These abbreviations need confirmation: Grand Merchant (office), Jera's Store, Caron Store, Semnadoc Cath., The Gods.
- Only the palette indices change. Size, format and palette are the same as the source GIM, so there is no hardware risk.
