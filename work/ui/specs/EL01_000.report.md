# EL01_000 - UI texture report

Spec: `work/ui/specs/EL01_000.json` (generated by `work/ui/scratch_EL01_000_gen.py`; edit the generator, not the
long erase list, if the button cleaning has to change). Build/preview:
`PYTHONUTF8=1 python tools/img_text.py work/ui/specs/EL01_000.json` -> `work/build/img/EL01_000.GIM`,
`work/ui/preview/EL01_000.png`. Output is the same size as the source (263460 bytes), header and palette unchanged.

## What is on the sheet
- Top-left button group (114 px wide, y 96..213; selected / normal / disabled at x 0 / 114 / 228): tavern menu.
- Bottom-left button group (96 px wide, y 216..453; x 0 / 96 / 192): status and item menus.
- Dark plates (x 390..496, y 192..215 and 236..247): resist / slaying screen headers.
- Pink glyph strips (x 286..512, y 120..443): stat screen, item / monster info, character list, spell lists.
- Unlike Elminage III there are no title plates (行動ルーチン, ダンジョン情報, 受け渡しフォルダ内), no 善/中立/悪,
  no 二つ名 and no second ブレス on this sheet; 追加 / 戻す are plain pink glyphs, not plates.

## Method
- Buttons. The disabled ワールドマップ button (228,196) is drawn without text in the original: it is the clean art.
  The three states share the same ornament layout (left swirl, a low hump under the text at x 23..44, a spike at
  x 49..57), so the clean selected and normal references (row 話す, y 156) are rebuilt as: `copy:` a clean column
  (x0+60) over x0+13/16..x0+47, then `fill:` 1-px runs that redraw the swirl edge and the hump, with each
  disabled-art colour mapped to the colour the same ornament pixel has in that state (mapping taken from the
  text-free columns; no fallbacks needed). The selected text has a soft glow that reaches into the swirl, so the
  selected state is cleaned from x0+13, the others from x0+16. Every other row of the state is then `blit:`ed
  from its reference. The bottom group has the same left art (verified pixel by pixel outside the text); its
  reference row 戻る (y 336) takes x 13/16..47 from the clean top references and is blitted to the other rows.
- Button labels: FONT10_16, left-aligned at x0+18 (where the Japanese starts); selected white with (127,32,23)
  outline, normal (252,222,184) with (31,21,15), disabled (102,102,102) with (31,21,15) (sampled from the sheet).
  All 3 states have identical wording. The disabled ワールドマップ stays blank, as in the original.
- Dark plates: the noise texture is not shared between plates, so 抵抗 / サブ are cleaned by tiling their own
  text-free strips (`blit:`), and the four other plates take that cleaned interior. White 12 px text with a
  (5,1,0) outline, as Elminage III.
- Glyph strips: the layout is the same as Elminage III's sheet (alpha masks identical apart from the items listed
  above), so its erase cells and label cells are reused, minus the items this sheet does not have; text colour
  is this sheet's (250,220,195). The 15 cells marked "uv_probe" were measured in the Elminage III game.
- Kept (not Japanese): GAME START, FACE LOAD, DATA INSTALL, EMPTY, L R arrows, / /, ＬＶ, ＥＰ ＨＰ, ＡＣ,
  ＥＰ ＧＰ, ％, ～, icons, MAGIC and SKILLS, FILE NAME, PREVIEW, GP.
- Verified with an erase-only render (`work/ui/scratch_EL01_000_eraseonly.json` -> preview copied to
  `work/ui/scratch_EL01_000_erased.png`): no Japanese pixels left; no pixel changed outside the button, plate and
  strip zones; the kept English / symbols are untouched (only anti-alias tails of the Japanese row above ＥＰ ＧＰ
  were removed).

## Terms
- Bound by HELP_TEXT titles: Items, Equip, Use, Give, Discard (HELP_TEXT 22:7; Elminage III used "Drop"),
  Appraise, Back, World Map, Svt. Bag (HELP_TEXT 54:7 / 222:7; "Servant Bag" is 79 px, the cell ~70).
- 呪文 = "Spells": HELP_TEXT 11:7 says "Spell", but the neighbouring button is "Items" and Elminage III uses
  "Spells". Lead: align HELP_TEXT 11:7 to "Spells", or switch this label to "Spell" (one-word change in the
  generator).
- No existing English (help title column empty): キャラ確認 Inspect, まとめて鑑定 Appraise All, 順番変更 Reorder,
  話す Talk (Elminage III), お金を山分け Split Gold, お金を集める Pool Gold (Elminage III lead decision; this game's
  currency is GP, "Split GP" is an option), キャラ詳細 Details (new; help: "Check a character's condition in
  detail").
- Monster-type codes as EL02_000: 神影 = Godshade = "Gs" (lead note), the rest as Elminage III.

## Risks / in-game checks
- UV rects are unknown for this game. Button labels stay inside the original text area. Strip labels use the
  Elminage III cells; where English is wider than the kanji (頭 体 手 足, 名前, the 36 px equipment cells) it relies
  on the same layout. Check: tavern menu, status screen buttons, item menu, Servant Bag screen (Add / Back),
  item / monster info, resists & slaying screen, character list, spell list.
- Selected-state buttons: the row-to-row dither noise of the original is replaced by the reference row's
  (invisible at 1x). The hump ornament under the text is reconstructed, not copied: compare one button in game.
- "Appraise All" (top) and "Split Gold" / "Pool Gold" (bottom, spacing 0) run close to the right-hand ornament,
  as the Japanese did.
