# EL02_001 - town facility and facility-action buttons (Bistel)

**0.1.16: buttons widened to 130 px** (spec 'widen': 16 px of plain body inserted at x+60, cells at
x = 130*state; sprite records in ANIME/MD02_004.ANM rewritten by tools/anm.py). Labels are one entry per
button, ink from x+17, up to 105 px, 16px font sp1 then sp0; nothing is squeezed any more and row 10 is
"Alchemy Storage". The tables below describe the original 114 px layout.

Spec: `work/ui/specs/EL02_001.json` (render: `PYTHONUTF8=1 python tools/img_text.py work/ui/specs/EL02_001.json`).
Preview: `work/ui/preview/EL02_001.png`. Erase-only render: `work/ui/scratch_EL02_001_eraseonly.png`.
Generator (scratch): `work/ui/scratch_EL02_001_gen.py` (`--erase-only` writes the same spec without labels).

Texts found: 23 labels x 3 states = 69 sprites. Translated: 69 (23 distinct strings). Nothing else on the
sheet (one opaque block 342x462).

## Layout (same as Elminage III's EL02_001)
- Button 114x18 at (114*state, 20*row); states x0 selected (silver/white), x114 normal (dark red), x228 disabled.
- Normal/disabled: every row is pixel-identical outside the text. Selected: the body carries a faint per-row
  red glow (x12-14, max diff 30/1020) and rows 16-19 (bottom border + soft shadow) vary per row; neither is text.
- Japanese ink sits at x18-103, rows 2-14 (outline/shadow x16-105, row 15). Left swirl ends at x14/15, a
  small spike sits at x50-56 near the bottom, the right swirl/cap starts at about x95.

## Method
- Reference row 11 (鍛冶, shortest): x16-47 (x15-47 in the selected state, to also remove the red glow column
  at x15), rows 0-15, blitted from the same row 44 px to the right (plain body x60-91).
- Every other row: x16-110 (selected: x15-110), rows 0-15, blitted from the cleaned reference. This also
  restores the spike and right swirl under long labels. Rows 16-19 and x0-14 / x111-113 are never touched.
- Verified with the erase-only render: normal and disabled rows equal the reference exactly; selected rows differ
  only at x12-14 (faint glow, max 30/1020). No Japanese pixels remain.
- Text: 16px game font, left-aligned, glyph cell at the button's row 0 (caps rows 1-13, descenders to 15; the
  descender outline touches border row 16, as in Elm III). Ink from x+17, at most 92 px (ink ends <= x+108).
  Fonts 16/sp1, then 16/sp0.
- Colours sampled from the original text: selected ink 255,255,255 / outline 126,31,21; normal ink
  252,222,184 / outline 30,22,15; disabled ink 102,102,102 / outline 39,32,26.
- Squeezed labels (0.1.14): `squeeze` draws ink + outline at natural width and narrows the result with an
  area filter, so the label stays anti-aliased (one entry per state, `outline` set). Before 0.1.14 it was cut to
  one-bit pixels and drawn as 8 outline copies + ink, which looked bold and jagged in game.

## Kept
- Left curl (x0-14), right cap (x111-113), bottom border and selected-state shadow (rows 16-19), the spike and
  right swirl (restored from the reference). No English, icons or numbers on this sheet.

## Risks / in-game checks
- Labels reach x+107/108 (the Japanese stopped at x+103, outline x+105); they stay inside the body, over the
  right swirl, before the cap. UV rects unknown: if the game crops the sprite narrower, row 0/1/3/6/19/20 ends
  would be cut.
- Squeezed labels (rows 3, 19, 20) are about 6-12% narrower than the others; fallbacks are listed above.
- "Berte's Tavern" and "Call Companions" use a 3 px word gap instead of 5 px.
- Abbreviation differing from the glossary: Alch. Storage (Alchemy Storage). "Treat/Retrieve" differs from
  the help menu name "Treat & Retrieve".
- Descender outlines (Shop, Stay, Appraise, ...) touch the bottom border row 16, as in the Elm III sheet.
